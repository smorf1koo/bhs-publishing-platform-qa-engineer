# Платформа публикации · QA Engineer · «Проверка основного пути на стенде платформы»

Тестовое задание на позицию QA Engineer (ручное тестирование и автотесты, стажёр / джун) в проекте «Платформа публикации игровых проектов», Bear Head Studio.
Нужно проверить учебный стенд платформы по требованиям: составить чек-лист и тест-кейсы, оформить баг-репорты
и написать e2e-тесты Playwright на основной путь — каталог, карточка проекта, загрузка демоверсии, модерация.

Задание — в документе
[`Тестовое_задание_QA_Engineer.pdf`](Тестовое_задание_QA_Engineer.pdf).

## Как сдать

Задание — в `Тестовое_задание_QA_Engineer.pdf`, материалы — в этом репозитории: нажмите «Use this template», чтобы создать свою копию. Ссылку на свой публичный репозиторий с решением пришлите на gpetrov@hse.ru. Вопросы — туда же.

## Состав пакета

| Путь | Что это |
|---|---|
| `Тестовое_задание_QA_Engineer.pdf` | задание: задача, входные данные, что сделать, как сдать |
| `starter/REQUIREMENTS.md` | требования к стенду |
| `starter/` | стенд на Vite + TypeScript без сервера, данные в JSON, Playwright с примером теста и генератором zip-архивов |

## Как начать

Нужен Node.js 20+.

```bash
cd starter
npm install
npx playwright install chromium
npm run dev          # стенд на http://localhost:5173
npm run test:e2e     # пример e2e-теста
```
